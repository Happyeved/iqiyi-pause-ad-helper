# iqiyi-pause-ad-helper

爱奇艺网页暂停广告处理脚本，支持鼠标和空格快速切换播放状态。

- **脚本功能**：处理暂停广告，支持画面单击、空格和全屏。
- **使用环境**：已在 Firefox + Tampermonkey 环境下测试。
- **当前版本**：1.0。

## 安装方法

1. 安装 Tampermonkey（油猴）。
2. [点击安装脚本](https://github.com/Happyeved/iqiyi-pause-ad-helper/raw/refs/heads/main/iqiyi-pause-ad-helper.user.js)。
3. 安装完成后，刷新爱奇艺视频页面。
